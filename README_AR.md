# لمعة ستوديو — مشروع تصميم عربي

نسخة أولية عملية لتطبيق تحرير تصميمات عربية، مستوحاة من فئة تطبيقات التصميم الشائعة، وليست نسخة من Canva أو من كود أو هوية أي تطبيق آخر.

## ما الذي يعمل في هذه النسخة؟

- ستة قوالب قابلة للتخصيص: عصرية، عرض خاص، أناقة هادئة، جمال وأناقة، مشروعك، واقتباس ملهم.
- تعديل العنوان والنص المساند والشريط العلوي، مع معاينة مباشرة.
- ست لوحات ألوان، وثلاثة مقاسات: منشور 1080×1080، قصة 1080×1920، وملصق 1200×1600.
- تحكم بحجم العنوان والزخارف الخلفية، وإضافة صورة من الجهاز كخلفية.
- تصدير PNG. داخل غلاف Android يحفظ الصورة داخل `Pictures/Lamaa` ويفتح واجهة المشاركة الأصلية.
- حفظ ما يصل إلى 8 تصاميم على الجهاز عبر التخزين المحلي.
- واجهة عربية RTL متجاوبة، ونسخة ويب قابلة للتثبيت PWA بعد استضافتها عبر HTTPS، مع دعم العمل دون اتصال بعد أول زيارة.
- لا توجد حسابات مستخدمين أو إعلانات أو تحليلات أو استدعاءات API في هذه النسخة.

## تشغيل نسخة الويب محليًا

يمكنك فتح `index.html` لمراجعة التصميم، لكن بعض خصائص PWA والعمل دون اتصال تتطلب تقديم الملفات من خادم محلي أو استضافتها على HTTPS.

من داخل مجلد `lamaa-studio` شغّل:

```bash
python -m http.server 8080
```

ثم افتح `http://localhost:8080` في المتصفح. لا تُرفع الملفات التي تختارها إلى خادم في هذه النسخة؛ المعالجة محلية داخل المتصفح.

## بناء تطبيق Android

مجلد `android` مشروع Android Studio مستقل يستخدم WebView لعرض الملفات المضمّنة محليًا، ولا يحتاج إذن الإنترنت لتشغيل وظائفه الأساسية.

1. ثبّت Android Studio وJDK 17، ثم من SDK Manager ثبّت Android SDK Platform 36 وAndroid SDK Build-Tools المتوافقة.
2. افتح مجلد `android` في Android Studio. يستخدم `gradlew` و`gradlew.bat` مُشغّل تنزيل بسيطًا مرفقًا بالمشروع: يجلب Gradle 8.13 من نطاق Gradle الرسمي ويتحقق من SHA-256 المعرّف في `gradle-wrapper.properties` قبل تشغيله. يتطلب أول بناء اتصالًا لتنزيل Gradle وAndroid SDK إذا لم يكونا مثبتين بالفعل. يعتمد بناء GitHub Actions على Gradle المثبت في عامل البناء ولا يعتمد على هذا المشغّل.
3. اختبر التطبيق على جهاز أو محاكي فعليًا، خصوصًا اختيار الصور، وحفظ PNG، والمشاركة، واستعادة التصاميم بعد إغلاق التطبيق.
4. غيّر معرّف الحزمة `com.lamaa.studio` إلى معرّف فريد تملكه قبل النشر، في `android/app/build.gradle` و`namespace`، وحافظ على تطابقه مع إعدادات التطبيق.

### إنشاء مفتاح رفع خاص بك

لا تستخدم مفتاحًا مشتركًا من طرف ثالث، ولا تُرسل ملف المفتاح أو كلمة مروره إلى أي شخص. احتفظ بنسخة آمنة منه؛ تسليم ملف جديد لا يحلّ محل مفتاح رفع تستخدمه لاحقًا دون إجراءات استعادة.

باستخدام `keytool` المثبّت مع JDK:

```bash
keytool -genkeypair -v -keystore lamaa-upload.jks -storetype JKS -keyalg RSA -keysize 4096 -validity 10000 -alias lamaa-upload
```

احتفظ بالملف وكلمات المرور في مكان آمن خارج المستودع. لا ترفع `lamaa-upload.jks` أو كلمات مروره إلى GitHub.

بعد ذلك، من داخل مجلد `android` ابْنِ حزمة المتجر باستخدام خصائص Gradle التالية. استبدل المسار وكلمات المرور بقيمك، ولا تضع كلمات المرور في سجل عام أو سكربت مشترك:

```bash
./gradlew bundleRelease \
  -PLamaaStoreFile="/absolute/path/to/lamaa-upload.jks" \
  -PLamaaStorePassword="YOUR_STORE_PASSWORD" \
  -PLamaaKeyAlias="lamaa-upload" \
  -PLamaaKeyPassword="YOUR_KEY_PASSWORD"
```

في Windows استخدم `gradlew.bat bundleRelease` مع خصائص `-P` نفسها. ستُخرج المهمة ملف `.aab` تحت `android/app/build/outputs/bundle/release/` إذا كان Android SDK متوفرًا وكان البناء ناجحًا. لا تحتفظ بكلمات المرور في سطر الأوامر بعد الانتهاء.

## اختبار تلقائي عبر GitHub Actions

يوجد workflow في `.github/workflows/android-release.yml` يبني ويوقّع ويجري اختبارًا دخانيًا على محاكي عند الدفع أو إنشاء tag. يحتاج أسرار المستودع:

- `LAMA_STORE_FILE` (base64 للمفتاح)
- `LAMA_STORE_PASSWORD`
- `LAMA_KEY_ALIAS`
- `LAMA_KEY_PASSWORD`

راجع `ANDROID_BUILD_CLOUD_AR.md` و`TEST_REPORT_AR.md` للتفاصيل.
